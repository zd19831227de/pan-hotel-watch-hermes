# 三平台 EBK 数据指标叫法映射知识库（以携程叫法为锚）

> 创建日期：2026-08-25
> 适用范围：Pan Hotel Watch 三平台（携程 / 美团 / 飞猪）EBK 经营数据问答与简报口径统一。
> 锚点原则：**任何指标一律以携程的叫法为标准叫法**；用户用美团或飞猪的叫法提问时，
> 先换算到携程叫法再查询与回答。
> 证据来源：本表全部叫法取自系统三平台读取层源码原文（`backend/app/domain/browser/`
> 下的 `ctrip_ebooking_dataset_parsers.py`、`meituan_ebooking.py`、`fliggy_ebooking.py`）
> 与跨平台导出映射 `backend/app/domain/exports/ebk_business_metrics.py`
> （`CORE_METRIC_CANDIDATES`，当前唯一权威跨平台映射表）。

## 1. 总纲：完核销数据的三平台叫法（最重要的一条）

**同一类"实际经营结果"数据（客人已完成入住、离店，即已核销/完核销的实际到账金额和
实际销售间夜），三个平台用不同的字面叫法：**

- **携程叫「离店」**：如 离店销售额、离店间夜量。按**离店日期**统计，代表客人完成
  离店后确认的实际经营结果。
- **美团叫「入住」**：如 入住金额、入住间夜。按**入住日期**统计，代表已入住（核销）
  的实际到账金额与实际消费间夜。美团页面同屏还有"销售额/销售间夜"，那是**支付/售出
  口径**（未核销、可能取消），不要与"入住*"混用。
- **飞猪叫「在店」**：如 房费收入、在店间夜（"在店数据"段）。飞猪全站没有"离店"
  字样，"在店"段是当日已入住的实际收入与间夜，是飞猪侧最接近"完核销"的口径。

一句话记法：**完核销到账与实际销售间夜 = 携程「离店」= 美团「入住」= 飞猪「在店」**。

具体指标名：实际到账金额 = 携程"离店销售额" = 美团"入住金额" = 飞猪"房费收入"；
实际销售间夜 = 携程"离店间夜量" = 美团"入住间夜" = 飞猪"在店间夜"。

注意：三者统计日期维度不同（携程按离店日期、美团按入住日期、飞猪按当日入住），
**同一个自然日的数值不可跨平台直接对比**（详见 §9 口径警示）。

## 2. 统计维度（日期口径）叫法映射

三平台 EBK 页面对"按什么口径统计"的表达方式不同：

| 业务含义（携程叫法为锚） | 携程 | 美团 | 飞猪 |
|---|---|---|---|
| 预订口径（下单/支付，未核销） | 「预订」段 | 指标名前缀「销售*」（销售额、销售间夜） | 「预订数据」段（读取时自动点"昨日"） |
| 入住/在店口径（已入住未离店） | 「在店」段 | —（无独立在店段） | 「在店数据」段 |
| 离店口径（完核销实际结果） | 「离店」段 | 指标名前缀「入住*」（入住金额、入住间夜） | —（无离店概念，用"在店"近似） |
| 时间档位 | 实时 / 昨日 / 按日 / 按月（「离店·按月」为"总平台"口径的本月数据） | 页签：今日实时 / 昨日 / 近7天 / 近30天（无日期维度选择器，口径全靠指标名前缀区分） | 首页分「今日数据 / 昨日数据」；经营数据分「在店数据 / 预订数据」 |

携程"销售数据"页（数据集 `beneficial_data`，页面名"预订销售数据"）依次分
「预订 / 在店 / 离店」三个区块；美团没有日期维度选择器；飞猪没有"离店"字样。

## 3. 核心经营指标叫法映射总表（以携程叫法为锚）

每行含义：同一个业务指标，三平台页面/快照里的原文叫法。携程列同时给出系统内部
英文键名（美团/飞猪快照直接以中文原文为键）。

| 携程叫法（锚） | 业务含义 | 携程内部键 | 美团叫法 | 飞猪叫法 |
|---|---|---|---|---|
| 离店销售额 | 完核销实际到账金额（按离店日期） | `departure_sales_amount`；本月=`monthly_departure_sales_amount` | 入住金额（注意：美团页面的"销售额"是支付口径，不是到账口径） | 房费收入（在店数据段）；预订收入金额（预订数据段） |
| 离店间夜量 | 完核销实际销售间夜（按离店日期） | `departure_room_nights`；本月=`monthly_departure_room_nights` | 入住间夜 | 在店间夜（在店数据段） |
| 预订订单数 | 预订/支付口径订单量 | `booking_orders`；实时=`realtime_booking_orders` | 支付订单数 | 预订订单量 / 预订单数 / 订单数 / 支付订单数 |
| 间夜量（预订段） | 售出（支付）口径间夜，未核销 | `room_nights` | 销售间夜 | 预订间夜（别名"预定间夜"） |
| 在店间夜 | 当前在住间夜 | `in_house_room_nights`；实时=`realtime_in_house_room_nights` | —（未找到直接对应指标） | 在店间夜 / 今日在店 |
| 平均卖价 | 平均房价 ADR | `average_selling_price`；本月=`monthly_average_selling_price` | 平均房价 / 销售均价 | 间夜单价 / 均价 |
| 出租率 | 房量利用效率 | `occupancy_rate` | 满房率 | 入住率 |
| 成交率 | 下单/成交转化效率 | `transaction_rate`；漏斗口径=`booking_conversion_rate`、`realtime_booking_conversion_rate` | 支付转化率 / 成交率 | 预订转化率 / 转化率 |
| 紧张度 | 房量紧张程度（在店段） | `tightness` | — | — |
| 实时预订订单 | 当日实时预订 | `realtime_booking_orders` | —（待办卡的"待确认订单"是待办数，不是经营指标） | 今日预订 / 预订订单 |

跨平台导出时系统按上表"美团叫法/飞猪叫法"作为候选键取值（例如"销售额"统一列在
携程取 `departure_sales_amount`、美团取"销售额"页签值、飞猪优先取"房费收入"），
出处：`backend/app/domain/exports/ebk_business_metrics.py` 的 `CORE_METRIC_CANDIDATES`。

## 9. 口径警示（回答用户前必读）

1. **跨平台数值不可直接比较、不可相加**：携程"离店"月度数据是 EBK 页面"总平台"
   口径；美团/飞猪快照是各自平台口径。三平台数据只做**各自平台内**的环比/同比。
2. **统计日期维度不同**：完核销数据携程按**离店日期**、美团按**入住日期**、飞猪按
   当日**在店**，同一自然日三平台数值含义不同。
3. **美团的"核销"不是经营主指标**：美团页面"核销"一词只出现在神券/促销活动指标里
   （核销、用神券核销金额、用神券离店订单数等）。表达"完核销经营结果"时用
   "入住金额/入住间夜"，不要引用神券核销指标。
4. **美团"销售额/销售间夜"≠ 到账**：它们是支付/售出口径；到账口径是"入住金额/入住间夜"。
5. **空白 ≠ 0**：导出/快照里空白表示该次读取页面未返回此数据，不代表数值为 0。
6. **飞猪"线上预订人数"可能是派生值**（详情页曝光人数 × 预订转化率），不是页面直读。
7. **携程服务概览四指标（PSI/点评分/5分钟回复率/收藏数）是昨日口径**；实时访客/实时
   在店间夜/实时预订订单是实时口径，混用前先对齐时间档。

## 10. 同义词速查索引（供检索分块命中）

每行是一个完整等价组：携程叫法 = 美团叫法 = 飞猪叫法（锚点在前）。

- 离店口径 = 入住口径 = 在店口径（完核销实际经营结果）
- 离店销售额 = 入住金额 = 房费收入（实际到账金额，完核销）
- 离店间夜量 = 入住间夜 = 在店间夜（实际销售间夜，完核销）
- 本月离店销售额 = （美团无按月离店页） = （飞猪无）——携程按月口径键 `monthly_departure_sales_amount`
- 预订段间夜量 = 销售间夜 = 预订间夜（售出/支付口径间夜）
- 预订订单数 = 支付订单数 = 预订订单量（订单量）
- 实时预订订单 = （美团无） = 今日预订
- 在店间夜 = （美团无直接对应） = 在店间夜 / 今日在店
- 平均卖价 = 平均房价 = 间夜单价（ADR；美团另叫销售均价，飞猪另叫均价）
- 出租率 = 满房率 = 入住率
- 成交率 = 支付转化率 = 预订转化率（转化率）
- 列表页曝光量 = 曝光量 = 列表页曝光人数（曝光）
- 详情页访客量 = 浏览人数 = 详情页曝光人数（浏览）
- 访客量 = 访问人数 = 线上预订人数（访客；飞猪可能为派生值）
- 实时排名 = 同行排名 = （飞猪无，用 MCI 表达竞争力）
- PSI服务质量分 = HOS分 / 服务分 = （飞猪无）
- 酒店点评分 = 评价分 = 客人点评得分（点评分）
- 5分钟回复率 = 5分钟确认率 = （飞猪无）
- 竞争圈平均 = 同行均值 = （飞猪无）
- 竞争圈排名 = 同行排名 = （飞猪无）
- 流失订单量 = 流失订单量 = （飞猪无）
- 流失间夜量 = 流失间夜量 = （飞猪无）
- 流失订单金额 = 流失订单金额 = （飞猪无）
- 紧张度 = （美团无） = （飞猪无，携程在店段特有）
- 引流价 = 引流价（美团特有） = （飞猪无）
- MCI酒店竞争力指数 = （美团无） = 飞猪特有
- 经营概览（携程）= 数据中心首页（美团）= 工作台首页（飞猪）
- 预订销售数据（携程）= 交易分析（美团）= 经营数据（飞猪）
- 流量数据（携程）= 流量分析（美团）= 经营数据-流量数据段（飞猪）
- 流失分析（携程）= 流失指标并入流量/服务分析（美团）= 无（飞猪）

- 促销效果/已参加促销（携程）= 促销活动（美团）= 促销活动（飞猪）
