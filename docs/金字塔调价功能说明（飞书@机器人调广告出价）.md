# 金字塔调价功能说明（飞书 @机器人 调广告出价）

> 版本：2026-09-03 · 分支 `feat/pyramid-bid-adjust` · **尚未提交，等业务确认**
>
> 一句话：以后想调携程「金字塔」广告的点击出价，不用登 EBK 后台翻页面了，
> 直接在飞书群里 @机器人 说一声，机器人查价、发确认卡、你点一下，它就去改。

---

## 1. 这个功能是干什么的

携程 EBK 后台有个「广告营销 → 金字塔」页面，里面是你家的广告推广计划
（比如按投放时段建的 `14--16`、`22--24`、`20--22`，还有「智能投放」）。
每个计划有一个**点击出价**（客人点一次你的广告，你愿意付多少钱，目前是 5.5 元）。

以前调这个出价要：登录 EBK → 广告营销 → 金字塔 → 找到计划 → 点修改 → 改出价 → 提交。
以后只要在飞书群里发一句话。

## 2. 怎么用（业务同学看这里）

**第一步：先看看现在多少钱（随时可查，不会有任何改动）**

```
@机器人 金字塔出价
```

机器人会回一张卡，列出每个计划的：出价、今日预算、已花费、状态（推广中/日预算不足等）。

**第二步：说要调哪个、调到多少**

```
@机器人 金字塔调价 14--16 出价调到6
```

说法不用一模一样，这些都认：
- `金字塔调价 14--16 出价调到6`
- `把金字塔14--16的出价调到6元`
- `金字塔 22--24 出价改为5.5块`
- `金字塔 20--22 调到4.2`（省掉「出价」两个字也行）

**第三步：点确认卡**

机器人会先回一张**审批卡**，写清楚：

- 计划名称（14--16）
- 当前出价 → 目标出价（¥5.5 → ¥6）
- 这个计划的状态、今日预算
- 风险提示

你点 **「确认调整出价」** 才会真的去改；点 **「暂不调整」** 或不理它，就什么都不会发生。

**第四步：等结果卡**

点完确认后机器人自动干活，几分钟内回一张结果卡：
- 成功：显示「填入出价 6 / 页面回读 6」，表示携程页面上已经改好了；
- 没成功：会告诉你卡在哪一步、建议怎么处理（见第 4 节）。

## 3. 安全机制（为什么要点一下确认）

跟现在的「房价调价」是同一套规矩，权限也完全靠齐：

1. **群绑定**：只有绑定了 EBK 调价账号的飞书群才能用（就是现在发「把今天大床房调到420」的那个群绑定）。没绑定的群发指令，机器人会提示先去控制台绑定。
2. **必须人工确认**：机器人永远不会只凭一句话就直接改价，必须有人在卡片上点「确认调整出价」。
3. **只认你说的价**：执行的时候用的是你消息里写的那个价（也是卡片上确认的那个价），中途谁也改不了。
4. **改前再核对一遍**：点确认后，机器人会先打开修改页核对：计划名字对不对、出价输入框找没找到、目标价是不是低于页面「起价」（页面写着起价 2.1，低于它携程不让提交）。任何一项不对就自动停，不会瞎改。
5. **改后回读验证**：提交后机器人会重新读一遍列表页，确认携程页面上的出价真的变成了目标值，变了才算成功；对不上会明确说「回读不一致，需人工复核」。
6. **账号类型限制**：只有「非直连（non_direct）」的携程 EBK 账号允许自动调整；直连或未确认的账号只出参考卡、不出现确认按钮（跟房价调价同一句话术）。
7. **全程留痕**：每次预览、每次点卡、每步执行结果都入库，事后可查。

## 4. 哪些情况会自动停下来（这是好事）

| 情况 | 机器人的反应 |
| --- | --- |
| 出价低于页面起价（比如调到 2 元，起价 2.1） | 改之前就拦下，提示提高出价 |
| 出价填进去读回来对不上 | 不提交，提示人工看页面 |
| 提交后页面价格没变 | 明确说「提交未生效」，不出假成功 |
| 页面改版/结构认不出来 | 自动停（页面结构变化），提示人工处理 |
| EBK 掉登录、要验证码 | 自动停（需要人工处理），跟其它功能一样 |
| 想改的计划名不存在 | 列出当前所有计划名让你重发 |

## 5. 现在不支持的（说清楚，免得误会）

- **只支持携程**。美团/飞猪账号绑定的群发这个指令，会提示不支持。
- **只调「点击出价」**。今日预算、推广日期、暂停/恢复计划这些暂不支持（后续可以加）。
- 金字塔如果开着「智能调价」，携程实际扣费会在你设的出价 **0.7~1.3 倍**之间浮动——
  这是你自己在携程页面上开的开关，机器人不会动它，卡片上会提示一句。
- 一次只改一个计划。要改多个就多发几条指令、分别确认。

## 7. 常见问题

**Q：我发「金字塔今天投放怎么样」怎么不是这个功能？**
A：那是数据问答，还是走原来的智能问答。这个功能只认「出价/调价/推广列表」这类指令。

**Q：点完确认要等多久？**
A：一般 1~2 分钟内回结果卡（要开页面、填价、提交、回读）。

**Q：改错了能改回来吗？**
A：能，再发一条指令把出价调回去就行，同样要确认。

**Q：为什么我的群里点确认没反应/没有确认按钮？**
A：大概率是绑定的 EBK 账号是直连或未确认类型（只允许参考，不允许自动改），按卡片提示处理。
